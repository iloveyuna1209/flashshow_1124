# 大模型取名冷知識｜11/24 閃電秀

以 **3D Diorama / 玻璃擬態** 視覺敘事呈現三大 AI 模型家族命名邏輯（OpenAI 宇宙星體 / Anthropic 文學創作 / Google 化學元素）與個人彩蛋（香水濃度階梯）的 14 頁互動動畫簡報。

## 啟動方式

```bash
npm install
npm run dev
```

或離線放映已打包版本：

```bash
npm run build
npm run preview
```

## 快捷鍵

- `→` / `Space` / `左鍵`：下一步動畫或下一頁
- `←` / `右鍵`：上一步
- `F`：切換全螢幕
- `Home` / `End`：跳至首頁 / 尾頁
